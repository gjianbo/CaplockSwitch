## 这个版本修什么

修复「配置忽略应用后，截图放进剪贴板却 `Ctrl + V` 粘不出来」的问题。

具体表现：用 PixPin 截图后剪贴板里**确实有图片**，但按 `Ctrl + V` 没反应；
把该程序从忽略列表里删掉就完全正常，加回去又复现。截其他内容不受影响。

这是 v1.1.1 之后继续定位到的问题（v1.1.2 只是本地验证版，未发布）。

## 根因

CapsSwitch 不调用任何剪贴板 API，键盘钩子也只对 `Caps Lock` 做判定，
`Ctrl + V` 一律原样放行。所以问题不在剪贴板内容，而在**忽略判定这条链路
把键盘输入事件拖住了**。

旧实现里，只要配置了忽略应用，每次前台窗口变化都会：

```
前台变化 → 投递消息 → Ignore_Recompute() → 解析前台进程名
         → OpenProcess →（失败时）全量 Toolhelp 进程快照
```

而进程名解析**失败的结果不入缓存**。截图时前台在「被忽略程序 ↔
PixPin 遮罩 / 工具条 ↔ 目标程序」之间高频切换，其中一部分窗口
（桌面、受保护进程等）必然解析失败，于是反复做全进程快照 ——
这些操作全压在**承载低级键盘钩子的那条消息循环**上。剪贴板图片的
延迟渲染（跨进程 `WM_RENDERFORMAT`）对输入时序特别敏感，表现出来就是
`Ctrl + V` 按下去没反应。删掉规则时这条链路直接返回，所以完全正常。

## 改法：运行时零进程 API

不是继续给旧链路减开销，而是把它整个换掉：

- 新增 `Ignore_RebuildPidSet()`：**一次** Toolhelp 快照，把所有名字命中
  忽略规则的进程 PID 收进整数集合。只在启动、用户修改忽略列表、
  以及约每 5 秒一次的低频定时器里执行。
- `Ignore_Recompute()` 改成纯内存操作：`GetForegroundWindow` →
  `GetWindowThreadProcessId` → PID 整数查找。**不再有 `OpenProcess`、
  不再有快照、不再有字符串比较、不再刷托盘**。
- 前台变化回调只记一个 PID，**不投递任何消息**，保持 O(1)。
- 判定改由 500ms `WM_TIMER` 驱动。`WM_TIMER` 是消息队列里优先级最低的
  消息，系统只在没有输入消息时才生成它，不会挤占键盘事件派发。
- 键盘钩子的 `IsIgnoredForeground()` 现在只是读一个 BOOL，
  连兜底路径里的消息投递也删掉了。

`Process_GetImageBaseName()` 保留，但只剩用户点「添加...」打开应用
选择器时才会调用 —— 那不在输入路径上。

取舍：忽略规则对**程序启动之后才运行的进程**最多延迟 5 秒生效。
对悠悠远程这类常驻软件没有影响。

## 升级方式

从托盘退出旧实例，用新 exe 覆盖后重新启动即可，配置文件
`%APPDATA%\CapsSwitch\config.ini` 不受影响。

右键看 exe 属性，版本号应是 **1.1.3**。

## 按键行为（未变）

| 组合 | 行为 |
|---|---|
| 单独按 Caps Lock | 发送你配置的输入法切换快捷键（默认 Ctrl + Space） |
| Shift + Caps Lock | 放行给系统，执行原生大写锁定 |
| Ctrl + Caps Lock | 切换「启用 / 暂停」，两种状态下都有效 |
| Alt / Win + Caps Lock | 只吞掉 Caps，不做任何动作 |
| 暂停状态下 | 除 Ctrl+Caps 外完全不干预 |
| 忽略列表中的程序位于前台 | 以上 Caps 行为全部让路，原样透传 |

另有全局热键 `Ctrl + Alt + C`，与 `Ctrl + Caps` 等效。

## 零运行时依赖

静态 CRT 构建，导入表只有 `ADVAPI32 / COMCTL32 / GDI32 /
KERNEL32 / SHELL32 / USER32` 六个系统 DLL —— 没装 VC 运行库的
机器也能直接跑。CI 会用 `--selftest` 走完初始化链路并扫导入表，
两项都通过才发版。

## 已知限制

- UAC 提权窗口、以及部分以管理员权限运行的全屏程序收不到按键
  （Windows UIPI 机制限制）。需要的话把 manifest 里的
  `requestedExecutionLevel` 改成 `requireAdministrator` 重新编译，
  代价是每次启动弹 UAC。
- 输入法切换快捷键若被其他软件占用，本程序不做规避，
  请在设置里换一种模式（`Win + Space` / `Shift + Space` /
  `Ctrl + Shift + Space`）。
